# salimmohamed/homebrew-tap

Homebrew casks for [T3 Isle](https://github.com/salimmohamed/t3isle).

```sh
brew install --cask salimmohamed/tap/t3-isle
```

This is the recommended way to install T3 Isle. The build isn't notarized yet, so the cask clears the download flag after install and T3 Isle opens without the "Open Anyway" step. Update with `brew upgrade --cask t3-isle`. Each T3 Isle release updates the cask here.
